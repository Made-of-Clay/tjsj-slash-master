# Candy — Blender source

Low-poly wrapped sweet built from `src/content/models/candy/candy-design.jpeg`
(front / side / top reference sheet). Generated by script, not hand-modelled:

```
./tmp/blender-4.5.15-linux-x64/blender -b -P src/content/models/candy/candy.py [-- --no-render]
```

Outputs: `candy.blend` (editable scene), `candy.glb` (Y-up, materials baked),
`previews/{front,side,top,hero}.png`.

Boot fetches it and normalises it to `size` (1.1); `../README.md` has the
flatten. Everything is solid white-ambient Principled — no transparency, no
textures. The stripes are per-face material indices, which the flatten turns
into vertex colours, so the candy costs three materials but no map.

## Shape rules

- Body is a plain 18 × 10 ellipsoid (1.00 × 0.66 × 0.80). No boolean, no pockets:
  the sweet is opaque here, so the reference's candied centre is just `#f3a978`.
- The ribbon is **two closed rectangular tubes** riding a helix on the body
  surface (1.15 turns, x ±0.425), orange in front of blue. Each ring is offset
  along the ellipsoid normal, never along ±Y, so the band hugs the shell.
- Both ends taper to 90 % narrower and sink 0.10 along the normal: a flat,
  full-width cut end sticks out of the shoulder as a visible flap.
- Each fan wrapper is one loft of six elliptic rings along x — buried at 0.40,
  pinched at 0.50, opening to 0.80 — with a `cos(3θ)` pleat growing toward the
  rim. The twist comes from rotating each ring's seam phase (0 → 0.35 → −0.35).
- Blue is a 3-of-12 sector band whose start advances 3 sectors per ring, so the
  stripe spirals along the twist instead of ringing it.
- Fan caps are n-gons; every object is watertight (0 non-manifold edges, 0
  degenerate faces, no loose verts).

## Tuning

`BODY` (ellipsoid radii), `RIBBON` (turns, span, strand width/height, phase
gap, lift), `WRAPPER` (ring table `x, ry, rz, phase, pleat`, stripe width) and
`COLOURS`.

## Budget

900 tris — body 324, ribbon 296, wrapper 280 (144 each). 27.6 kB GLB. Drawn at
~1/13 of the viewport height (~55 px), so the pleats are the only shape detail
that pays for itself; the ribbon is 4-sided and the body is 18 segments.
